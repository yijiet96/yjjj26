但**整套程式現在已經寫好並通過測試**了,如果你只想趕快看到每日選股結果,

cd ~/Downloads/stock-factor-model      # 進到專案資料夾

## 📚 先讀:終端機 30 秒入門(很重要,只讀一次)

- **終端機(Terminal)**:一個可以用「打字」叫電腦做事的黑底白字視窗。
- **怎麼打開**:按鍵盤 `Command(⌘) + 空白鍵` → 跳出搜尋框 → 輸入 `Terminal` →
  按 `Enter`。一個視窗就開了。
- **怎麼執行指令**:把指令**貼上去**(貼上是 `⌘ + V`),然後按 `Enter`。
- **怎麼知道做完了**:畫面最後出現一行結尾是 `$ ` 或你的名字,游標在閃,代表它在等你下一個指令。
- **打密碼時看不到任何字?** 這是**正常的**!Mac 的終端機輸入密碼時不會顯示任何符號,
  你照打,打完按 `Enter` 就好。
- **不用怕弄壞電腦**:這份手冊的指令都很安全。真的卡住,直接把畫面截圖丟回來問我。

> 💡 小技巧:遇到「複製這段指令」時,把整段(含符號)一起複製,貼到終端機按 Enter。

## 第 1 步:安裝 Python(模型運算的引擎)

我們用最簡單的「下載安裝檔、雙擊安裝」方式,不碰終端機。

1. 打開瀏覽器,前往 **https://www.python.org/downloads/**
2. 點最上面那顆大大的黃色按鈕「**Download Python 3.x.x**」(版本是 3.12 或 3.13 都可以)。
3. 下載完成後,到「下載」資料夾,**雙擊**那個 `.pkg` 檔。
4. 一直按「**繼續 / Continue**」→「**同意 / Agree**」→「**安裝 / Install**」。
   中途會要你輸入**開機密碼**(就是你開 Mac 的密碼,看不到字是正常的),打完按 Enter。
5. 裝完後,安裝程式視窗裡會有一個叫 **「Install Certificates.command」** 的檔案,
   **雙擊它執行一次**(這能避免之後抓資料時的網路憑證錯誤)。看到它跑完出現
   `[Process completed]` 就可以關掉。

**驗證安裝成功**:打開終端機(⌘+空白 → Terminal),貼上這行按 Enter:
```bash
python3 --version
```
✅ 你應該看到類似 `Python 3.12.4` 的字。看到版本號就成功了。

## 第 2 步:安裝 Claude Code(一行指令)

在終端機貼上這行,按 Enter:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
這會自動下載並安裝 Claude Code,不需要其他東西。跑完會出現安裝成功的訊息。

**讓終端機認得 claude 指令**:安裝完**先把終端機視窗關掉,重新開一個**(這步驟很關鍵,
能讓設定生效)。然後驗證:
```bash
claude --version
```
✅ 看到一個版本號(例如 `2.x.x`)就成功了。

> ❗ 如果出現 `command not found: claude`,先別慌,跳到本手冊最後的「疑難排解 Q1」。

## 第 3 步:把專案檔案放到電腦上

你在對話裡下載的 `stock-factor-model.zip`,預設會在「下載」資料夾。

1. 打開「**訪達 / Finder**」→ 左側點「**下載項目**」。
2. 找到 `stock-factor-model.zip`,**雙擊它**。Mac 會自動解壓縮,旁邊多出一個
   叫 `stock-factor-model` 的**資料夾**。
3. 回到終端機,我們把工作位置切換到這個資料夾。貼上(整段一起):
```bash
cd ~/Downloads/stock-factor-model
```
4. 確認位置正確,貼上:
```bash
ls
```
✅ 你應該看到一排檔名:`CLAUDE.md`、`README.md`、`config`、`src`、`requirements.txt` 等。
看到這些就代表你「人」已經站在專案資料夾裡了。

> 💡 `cd` = change directory(換資料夾);`ls` = list(列出裡面有什麼)。
> `~` 代表你的個人家目錄。

## 第 4 步:建立 Python 虛擬環境並安裝套件

「虛擬環境」是一個專屬這個專案的乾淨小空間,套件裝在裡面不會弄亂你的電腦。

1. **建立**虛擬環境(叫 .venv):
```bash
python3 -m venv .venv
```
(跑完沒訊息是正常的,代表成功。)

2. **啟動**它:
```bash
source .venv/bin/activate
```
✅ 成功的話,你會看到指令最前面多出 **`(.venv)`** 這個小標記。
**這代表你進到專案的小空間了。**(每次新開終端機要重跑這行,見第 8 步。)

3. **安裝**所有需要的套件(pandas、yfinance、FinMind 等):
```bash
pip install -r requirements.txt
```
這步會跑 2–5 分鐘,畫面會一直滾很多字(下載進度),**這完全正常**。
✅ 最後看到 `Successfully installed ...` 一長串套件名稱就成功了。

## 第 5 步:申請資料金鑰並填入 .env

模型要上網抓股價與財報,需要兩把「鑰匙」(API key)。都有免費額度。

1. **FinMind(台股資料)**:到 https://finmindtrade.com/ 註冊 → 登入後在會員中心/
   API Token 頁面複製你的 token。
2. **Financial Modeling Prep(美股財報)**:到 https://site.financialmodelingprep.com/
   註冊 → 在 Dashboard 複製 API Key。(若你初期只想做台股,這把可以晚點再辦。)

3. 把範本複製成正式設定檔。在終端機(確認還在專案資料夾、前面有 `(.venv)`)貼上:
```bash
cp .env.example .env
```

4. 打開 `.env` 來填鑰匙。用內建文字編輯器打開:
```bash
open -e .env
```
TextEdit 會跳出來,內容長這樣:
```
FINMIND_TOKEN=your_finmind_token_here
FMP_API_KEY=your_financial_modeling_prep_key_here
```
把 `your_..._here` 換成你剛剛複製的鑰匙(等號後面**不要留空格、不要加引號**),例如:
```
FINMIND_TOKEN=eyJhbGciOi...(你的長字串)
FMP_API_KEY=abcd1234...(你的字串)
```
改好後按 `⌘ + S` 存檔,關掉 TextEdit。

> 🔒 安心:`.env` 已被設定為**不會上傳、不會外洩**,鑰匙只存在你自己電腦上。

## 第 7 步:用「分階段指令」指揮 Claude Code 建模型 🚀

**核心紀律:一次只做一個階段,它做完、你看過、確認沒問題,才叫它做下一階段。**
下面每一段「框框裡的話」就是你要貼給 Claude Code 的指令(直接複製貼上、按 Enter)。

過程中 Claude Code 要修改檔案或執行程式時,會**停下來問你同不同意**,
你看一下、覺得合理就選同意(通常按 `y` 或選 Yes)。

---

**▶ 階段 0:讓它先讀懂專案(先不要寫程式)**
```
請完整讀 CLAUDE.md 與 config/ 底下三個 YAML 檔。讀完用三句話總結這個專案的
目標、五層架構、以及三大偏誤防線,讓我確認你理解正確。這一步先不要寫任何程式。
```

**▶ 階段 1:資料層(只先做台股)**
```
進入階段一。只針對台股、只先做「價量 + 財報」的抓取與 point-in-time 對齊,寫進
src/data。財報務必用公布日對齊。完成後在 tests/ 寫驗證,並抓台積電(2330)近幾期
資料印出來,讓我人工核對日期沒有用到未來資料。在我確認前,不要進入因子層。
```
👉 它跑完後,看它印出的日期樣本是否合理。OK 再貼下一段。

**▶ 階段 2:因子層(先各構面一個)**
```
進入階段二。先只實作四個代表因子:淨值市值比(value_bm)、外資買超
(chip_foreign_net)、12-1動能(tech_momentum_12_1)、ETF推估被動買盤
(flow_etf_estimated_buy)。用 2~3 檔個股手算對照,驗證公式無誤後再跟我說。
```

**▶ 階段 3:統計層**
```
進入階段三。實作 src/stats:去極值 → z-score標準化 → 產業中性化 → 合成,嚴格分
市場處理;事件型因子要照 CLAUDE.md 第6節走特殊處理(不標準化)。畫出因子分布圖
讓我檢查有沒有極端值或標準化錯誤。
```

**▶ 階段 4:回測層**
```
進入階段四。對前面那幾個因子做 IC、IC-IR 與十分位分組回測,要計入台股交易成本。
重點檢查分組報酬的單調性,輸出績效指標表(夏普、最大回撤等)與淨值曲線圖。
```

**▶ 階段 5:擴充與輸出**
```
進入階段五。擴充到 factors.yaml 全部因子、接入美股,並在 src/output 產出候選清單
(含四大構面分數拆解與風險旗標)。最後跑 walk-forward 樣本外驗證。完成後告訴我
怎麼執行、結果檔在哪裡。
```

> 🛟 全程萬用提醒語(它若想抄捷徑就貼這句):
> 「請檢查:財報有沒有用公布日?回測池有沒有含下市股?這個結果有沒有用到未來資料?」

## 第 8 步:之後每次要繼續做,怎麼開工?

關掉電腦後再回來,只要三個步驟:

1. 打開終端機,切換到專案資料夾:
```bash
cd ~/Downloads/stock-factor-model
```
2. 啟動虛擬環境(看到前面出現 `(.venv)` 就對了):
```bash
source .venv/bin/activate
```
3. 啟動 Claude Code,並接續上次的進度:
```bash
claude --continue
```
(`--continue` 會接回最近一次對話;想從頭開新對話就只打 `claude`。)

## 🧰 疑難排解(卡住就查這裡)

**Q1：輸入 `claude` 出現 `command not found: claude`**
終端機還沒認得它。貼這兩行(一行一行來),然後關掉終端機重開:
```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.zshrc
source ~/.zshrc
```
再試 `claude --version`。還是不行 → 跑 `claude doctor` 看它的診斷建議。

**Q2：`pip install` 跑到一半紅字報錯**
先確認前面有 `(.venv)`(沒有就重跑第 4 步的 activate)。
若是網路/憑證錯誤(SSL),回第 1 步雙擊那個「Install Certificates.command」。
然後重跑 `pip install -r requirements.txt`。

**Q3:打密碼時畫面完全沒反應**
正常!Mac 終端機輸入密碼時不顯示任何字元。照打、按 Enter 即可。

**Q4:抓台股資料時報錯,說額度或頻率超過**
FinMind 免費版有每小時請求上限。請 Claude Code「加入快取與自動重試,並降低請求頻率」,
或稍等一小時再跑。

**Q5:不小心關掉終端機或 Claude Code**
完全沒關係,什麼都不會壞。重做第 8 步那三行就回來了。

**Q6:看不懂 Claude Code 在問什麼,或它報錯**
直接把那段文字複製,貼回來問我,或在 Claude Code 裡直接打中文問它
「這個錯誤是什麼意思?請幫我修」。它會自己除錯。
